MiniCPM-V 4.7 Image Analyzer

Upload a reference image or capture a baseline snapshot of a healthy site. Later checks compare the live page against the stored baseline (visual + text) for health / defacement monitoring.

Token counts measured 2026-10-17 on prod towers, same image: f16(:8080)=489 vs -4x(:8081)=1851 prompt tokens. The "-4x" file is the HIGH-detail one (4x downsample = 256 tok/tile); plain f16 is 16x downsample = 64 tok/tile. More detail always costs tokens — physics, not config. Re-measure: tests/test_tower_orientation.py.

Backend expects llama-server instances:
• fast/general tower on port 8080 (mmproj-model-f16.gguf, 64 tok/tile) — default
• detail/OCR tower on port 8081 (mmproj-model-f16-4x.gguf, 256 tok/tile)
Accessible over the network on port 8000.
Visual verification and baselines require Playwright + Chromium (see README).
Baselines are stored locally in the baselines/ folder.
