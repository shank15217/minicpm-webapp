MiniCPM-V 4.7 Image Analyzer

Upload a reference image or capture a baseline snapshot of a healthy site. Later checks compare the live page against the stored baseline (visual + text) for health / defacement monitoring.

Requires both llama-server instances if you want to switch modes.

Backend expects llama-server instances:
• 16x on port 8080 (mmproj-model-f16.gguf)
• 4x on port 8081 (mmproj-model-f16-4x.gguf)
Accessible over the network on port 8000.
Visual verification and baselines require Playwright + Chromium (see README).
Baselines are stored locally in the baselines/ folder.
